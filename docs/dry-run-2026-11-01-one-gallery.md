# Dry run — vios-journey against the ONE Gallery deliverables (2026-11-01)

Purpose: test the Stage 2 and 3 skills, written from the manuscript on 2026-11-01, against the only client where the Practice has produced the real deliverables. Method: compare the skills' prescribed outputs with the ONE Gallery Journey Map v2.2 (Oct 2026, BG), the May 2026 Reasoning Note, Stage 3 Handoff, Journey Design (28 pages) and Choreography. The skills were not run blind, since the real outputs were read first; the comparison is structural and the fixes are in the skills.
