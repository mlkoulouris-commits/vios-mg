# Filter test — sharpening batches (Atelier del Gelato, fresh derivation 2026-11-01)

Test (`brand-book.md` › Filter test): **Is this talking to the order?** — does it hurry her, sell to her, or speak to no one in particular? Pass = no. BG: **„Говорим ли на поръчката?"** — бързаме ли, продаваме ли, говорим ли на никого?

Derived on 2026-11-01 from `diagnosis.md` (persona fear "being processed as one of many"; the founder's hard case "Next!" and the rushed counter; Role Peer; differentiator "a question and a note") and `persona-bible.md` v1.0 (is/is-not pairs, never-list). The October engagement's test (archive) was derived from Brand Book v3 and landed on the same trait with different wording; this run did not reuse its batches. Lines below are new except the brand's own fixed lines (the ritual question, the Note hand-over), which are facts from the fact sheet.

Regression set for the yearly review: every line in batch A must pass; every line in batch B must fail. A line that moves batches means the test, or the brand, has changed; log it below.

## Boundary cases noted

- "Happiness is an attitude." — lock-up tagline. A brand asset, judged by `archive/naming.md`, not by the test. Said to a person it would fail the third marker; it is never said to a person.
- "What are we celebrating today?" — recommended editorial line (open-facts 30). Both a brand asset and a line said to a guest; passes the test in that use. The only tagline candidate for which this is true.
- "Italian joy crafted daily." — the current editorial line. Outside the test (brand asset); judged in `naming.md` and recommended dropped on distinctiveness, not on the filter test.
- „Ателието" / "the Atelier" — house spoken form; not a line, no verdict.
- "Thanks for waiting." at a Ring Mall queue — passes (a fact, no apology, no hurry); recorded because the mall queue is the test's hardest field (open-facts 9).
