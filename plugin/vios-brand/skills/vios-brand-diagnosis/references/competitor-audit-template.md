# Competitor audit — template (Worksheet 6)

The original spreadsheet is `Brand+Strategy+-+Worksheet+-+6+-+Competitor+Audit.xlsx` in Drive › BRANDING RESOURCES (file id 1VDImT_jBDdHVMpo3Tybf5-rTdyL0sIII). Copy it into the client's Drive folder as `competitor-audit_<client>_<YYYY-MM>.xlsx`, one sheet per competitor, plus Ideas, Opportunities and Sources sheets. Atelier's October 2026 audit is the worked example.

## Per-competitor sheet

Header: competitor name · address · Google rating (n reviews) · one-line description.

| Dimension | Findings | Score 1–10 |
| --- | --- | --- |
| Brand message | tagline / intro message, slogan, underlying core message | |
| Positioning | claimed difference, value proposition, uniqueness, defensibility, how it is communicated, features / benefits highlighted most | |
| Personality | defined archetype?, personality description, who it appeals to, voice / language, visual execution | |
| Brand identity | logo, colours, images, typography, packaging | |
| Website / UX | design, UX, mobile, photography style, blog content and frequency, contact methods, support hours | |
| Reviews | what guests praise, what they complain about, in their words | |

Scoring: 8+ green, 7 yellow, under 7 red. The scoring is not the point; the noticing is.

## Sources sheet
`Source | Used for`, every source dated. Review mining counts as a source; name the platform and the date pulled.

Minimum 5 competitors (the course), 10 recommended and 20 ideal (the manuscript), found by searching the client's own description plus location.
