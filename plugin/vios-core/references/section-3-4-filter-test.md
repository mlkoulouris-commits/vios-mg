## 3.4 The Filter-Test Pattern


## 3.4.1 What this section is for

A filter test is a single yes/no question, derived from the brand's character, that can be applied to any piece of content the brand produces. "Does this sound like [the character]?" is the form. A well-constructed filter test fails bad work and passes good work in varied registers. A badly constructed filter test fails everything (and becomes useless) or passes everything (and becomes meaningless).

The filter test is one of the practice's most useful instruments because it transfers brand judgement from the practice to the operation. Without a filter test, every piece of content — copy, menu language, signage, social posts, internal communications — has to be reviewed by someone with brand authority. With a filter test, the test does the work: a junior staff member writing a piece of content can put it through the test themselves and either pass it through or recognise that it needs reworking.

The pattern earns its own standalone section because it is used at every stage where the brand produces language. Stage 1 builds the filter test as part of the brand book. Stage 2 uses it to evaluate the language of the journey map and the Reasoning Note. Stage 3 uses it heavily — every script is run through the test before it is finalised. Stage 4 builds the test into the training materials so staff who improvise at the table can self-check.


## 3.4.2 What a filter test is, and what it is not


#### What it is

A filter test is a yes/no question. The question is derived from the brand's character — usually from a single dominant trait the character requires. Putting a piece of content through the question produces a clear answer: yes, the content passes; no, it does not.

The question is short. It can be remembered without consulting the brand book. It can be applied without training. It can be applied by anyone in the operation, at any level, to any content the brand produces.

The question is sharp. It distinguishes between content that the brand would produce and content that the brand would not. A test that passes everything is no test. A test that fails everything is also no test.

The question is operational. It tests language as the customer will encounter it, not language as the brand wishes it would be encountered. The test asks: would this sound like the brand if a customer read it tomorrow at the table?


#### What it is not

It is not a measure of quality. Content can pass the filter test and still be weak; content can fail the filter test and still be well-written. The test is character-fit, not quality. A piece of brand copy is judged on both axes: does it pass the filter test (character) and is it well-written (quality). Both are required.

It is not a substitute for the brand book. The brand book carries the strategic substance — purpose, vision, mission, audience, archetype, role, expression dimensions. The filter test is one instrument derived from the brand book, useful for quick evaluation of language. Decisions that go beyond language (room design, partner selection, menu architecture) require consultation of the brand book itself, not just the filter test.

It is not a single sentence imposed on every brand. Each brand's filter test is derived from its specific character. A Sage brand's filter test is different from a Defender brand's filter test. The pattern is the same — a single yes/no question — but the question itself is engagement-specific.


## 3.4.3 How to derive a filter test from brand character

The filter test is constructed from the brand character established at Stage 1. The derivation has four moves.


#### Move 1 — Identify the dominant trait

From the Brand Personality Workbook (Stage 1, step 2.1.2.8), identify the trait that most distinguishes this brand from its category. The trait is usually one the brand refuses — a trait the category embraces by default and that the brand has decided not to share. Effusion, brightness, anxiety, urgency, performance, familiarity, theatre — each is a category default that some brands refuse, and the refusal is the trait.

If the brand defines itself primarily by what it embraces rather than by what it refuses, the trait is the positive — restraint, confidence, warmth, patience, plainness, quiet. The test will then ask whether the content carries that positive.

The trait is one. A test that combines two traits ("is it restrained and warm?") fails because content can be one without being the other; the test then becomes ambiguous and stops doing work.


#### Move 2 — Phrase the question

The question takes the form of either "is this [trait]?" or "is this [opposite]?" The negative form is often sharper: "is this effusive?" generates clearer yes/no answers than "is this restrained?" because effusion is more recognisable than restraint. The test then passes content for which the answer is no.

The question is phrased in the brand's own vocabulary. A brand whose vocabulary uses "plain" can ask "is this fancy?" A brand whose vocabulary uses "considered" can ask "is this rushed?" The vocabulary connects the test to the brand book so the test reads as part of the brand, not as imported jargon.


#### Move 3 — Sharpen against false positives and false negatives

Draft pieces of content are put through the test in two batches. The first batch is content the brand would produce — good brand copy, good scripts, good menu language. All should pass. Any that fail are false negatives; the test is too strict and is rewritten.

The second batch is content the brand would not produce — category-default copy, content from competitors, deliberate parodies. All should fail. Any that pass are false positives; the test is too lenient and is rewritten.

The sharpening continues until both batches return the expected results consistently. The test that emerges is the brand's filter test.


#### Move 4 — Build the test into the brand book

The filter test is added to the brand book — usually within the Brand Personality section or the Core Message Blocks section, depending on where the practice has placed character-related material. The test is named, presented with a short rationale (one to two sentences), and shown with two or three worked examples (one or two passes, one or two fails). The brand book carries the test forward to every later stage of the engagement.

The test is also placed visibly in materials likely to be consulted under pressure — the operating handbook, the floor playbook, the wall chart. Staff who write content at any level can find the test quickly and apply it.


## 3.4.4 How to use a filter test in evaluation

The filter test is applied in three modes.


#### Mode 1 — Pre-write filter

Before content is drafted, the writer holds the question in mind. The question shapes the draft from the start — words and phrases that would fail the test are not written in the first place. A piece of copy drafted with the filter test active comes out closer to brand than a piece of copy drafted without it.

The pre-write filter is the most efficient use of the test. A writer who has internalised the test produces draft material that passes on the first attempt; the test functions less as a checkpoint and more as a constraint on the writing itself.


#### Mode 2 — Post-write check

Once content is drafted, it is put through the test. The reader of the draft holds the test as the question: is this [trait]? If the answer is no, the draft passes. If the answer is yes, the draft is rewritten.

The post-write check is faster than the pre-write filter — it takes seconds — but is less effective if the writer has not internalised the test. A writer who only uses the post-write check produces draft material that has to be rewritten more often. The pre-write filter is the better discipline; the post-write check is the safety net.


#### Mode 3 — External-content audit

Content the brand did not produce — partner-generated copy, marketing material from agencies, internal communications drafted by managers, social posts drafted by hired writers — is put through the test. Material that fails is sent back for rework with the test attached. The test thereby becomes the practice's instrument for keeping external partners aligned with the brand.

The external-content audit is one of the most valuable applications of the test. Most brand drift comes not from internal staff producing off-brand content but from external partners producing content that no one stopped. The filter test gives the practice a fast, reproducible way to stop it. The test does not require the auditor to understand the brand deeply; the auditor only needs to apply the test.


## 3.4.5 Failure modes

Filter tests fail in characteristic ways.


#### Failure 1 — Too lenient

A test that passes most content is too lenient. It is not doing the work of distinguishing brand from non-brand. The cause is usually a question that names a trait the brand shares with much of the category — "is this professional?" passes most hospitality content because most hospitality content is professional. The fix is to identify a trait the brand does not share with the category and phrase the question against it.


#### Failure 2 — Too strict

A test that fails most content is too strict. It is rejecting content the brand would produce, which makes the test impractical to apply. The cause is usually a question phrased against a small detail of expression rather than against the trait. "Does this use the word 'lovely'?" is too strict — the brand would use "lovely" sometimes; the test should fail effusion rather than specific words. The fix is to raise the test from the lexical level to the character level.


#### Failure 3 — Ambiguous in application

A test produces inconsistent yes/no answers across different evaluators. Two staff members applying the same test to the same content reach different conclusions. The cause is usually a trait that is named but not defined operationally — "is this anxious?" produces different answers from people with different baselines for anxiety. The fix is to define the trait with one or two concrete markers: "is this anxious — does it apologise, hedge, or seek reassurance from the reader?"


#### Failure 4 — The test outlives the brand

Brands evolve. A filter test built early in the brand's life may stop being correct as the brand matures or as the audience shifts. A test that no longer reflects the brand begins to fail content the brand would now produce. The fix is periodic review of the test — annually, as part of the standing rotation — to confirm the test still passes good current content and fails bad current content. Tests that no longer work are revised; the revision is logged with reasoning.


#### Failure 5 — The test replaces the brand book

Staff stop consulting the brand book and rely on the filter test for all brand judgement. The test was always a derivative of the brand book; without the brand book being read periodically, the test loses its connection to the deeper character and drifts. The fix is that the test is presented alongside the relevant brand-book section, not as a standalone instrument. Anyone using the test regularly should also be reading the source it derives from.


## 3.4.6 Worked filter-test examples

Three worked examples follow, each showing the test, the trait it derives from, the question's construction, and one or two example evaluations.


#### Example 1 — A brand whose character refuses effusion

Brand character (from Stage 1): the Quiet Refuser. Disposition: restraint, presence, considered confidence. The brand refuses the hospitality category's default of effusive welcome.

Dominant trait identified: refusal of effusion.

Filter test: Is this effusive?

Pass example: "Welcome — sit anywhere." Three words. No exclamation. No follow-up question piled on. The brand's presence is there; effusion is not. Test result: not effusive. Pass.

Fail example: "Welcome to our wonderful restaurant! We're so excited to have you here this evening!! Please follow me to your table, I'll take such good care of you tonight!" Multiple exclamations. Self-praise of the venue. Performative warmth. Test result: effusive. Fail.

Notes. The test is short, applies to any content (greetings, menus, signage, social), and produces clear results. A staff member writing a social post can apply the test themselves and recognise that drafting a post with three exclamation marks needs rework before it reaches the brand.


#### Example 2 — A brand whose character refuses performance

Brand character: the Confident Specialist. Disposition: expertise quietly held, no performance of expertise. The brand refuses the hospitality category's default of theatrical service.

Dominant trait identified: refusal of performance.

Filter test: Is this performed?

Pass example: Menu description: "Lamb shoulder, slow-cooked, served with the broth." Three facts. The dish is named. The method is named. The accompaniment is named. The reader knows what they will get; the brand has not performed its expertise. Test result: not performed. Pass.

Fail example: Menu description: "Our master chef's signature lamb shoulder, lovingly hand-prepared over twelve hours in our state-of-the-art kitchen, presented with a delicate jus crafted from the very same juices that have nurtured the meat throughout its journey." Praise of the chef. Theatrical adjectives. The dish performs itself before it arrives. Test result: performed. Fail.

Notes. The test distinguishes brand from category default. The category writes menu copy that performs; the brand writes menu copy that informs. Applied across the menu, the test produces consistency that the customer reads as the brand's confidence.


#### Example 3 — A brand whose character refuses anxiety

Brand character: the Patient Host. Disposition: unhurried, settled, the brand has time. The brand refuses the hospitality category's default of urgency.

Dominant trait identified: refusal of anxiety / urgency.

Filter test: Is this anxious? — does this hurry, hedge, or apologise pre-emptively?

Pass example: Internal communication to staff about a delay in produce delivery: "Tomorrow's lamb is delayed by a day. We'll run the duck through Friday lunch and the lamb returns Friday dinner. Specials board updated." Three sentences. Facts. No apology for what is not anyone's fault. No urgency in language. Test result: not anxious. Pass.

Fail example: Same communication, anxious version: "Hi team, sorry to bother you but unfortunately we have a small issue with the lamb tomorrow!! The delivery has been delayed so we'll have to run the duck instead which I'm sorry about, hopefully this won't cause too much trouble. Please update the specials board ASAP and let me know if there's any issue!!" Pre-emptive apology. Hedging. Multiple urgency markers. Test result: anxious. Fail.

Notes. The test applies as much to internal communications as to customer-facing material. A brand whose character is calm produces calm staff communications; a manager who writes anxious staff communications produces an anxious culture, regardless of what the customer-facing brand looks like. The filter test catches this drift before it becomes operational.

These three examples share the pattern. Each starts from the brand character. Each names one dominant trait. Each phrases the question against the trait. Each shows one pass and one fail, with the reasoning that produced each verdict. A practice that has built filter tests across multiple engagements accumulates a library of these examples that future engagements can consult — not to copy, but to see the pattern in worked form before constructing a new test from a different character.
