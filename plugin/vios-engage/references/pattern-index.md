# Pattern index

The starting set of `vios-intake` move 3 is pulled from here, not from four chapters. One line per pattern: code · name · when to use · where the full form lives (when to use, what it produces, what it asks, failure mode). Only patterns the repo text holds; a pattern is added here by `vios-harvest` step 1 when a stage harvest records it, as **candidate** on first use and promoted when a second engagement confirms it (the harvest's own rule). Nothing here is a method change; the chapters stay the source.
