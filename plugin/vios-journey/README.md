# Vios Journey

Stages 2 to 4 of the Vios Practice: where the brand book becomes the room, the floor and the team. Consulting engagements that follow `vios-brand` and precede the hand-off to the operation. Requires `vios-core`.

| Order | Skill | Stage | Reads | Writes |
| --- | --- | --- | --- | --- |
| 1 | **vios-journey-map** | 2 | the brand book (six intake elements), the fact sheet | `journey/journey-map.md` (five bands), `reasoning-note.md`, `handoff-to-design.md`; updates `brand-book.md` › Journey for the marketing skills |
| 2 | **vios-journey-design** | 3 | the map, the Reasoning Note, the operating concept, the two libraries | `journey/design/pages/M01…`, `choreography.md`, `recovery.md`, `briefs/` |
| 3 | **vios-training-programme** | 4 | the design, the brand book, the map | `training/` staff stack and management stack, cadence calendar, handoffs, retrospective |

`references/` holds the manuscript chapters verbatim: Stage 2 (`stage-2-journey-map.md`), Stage 3 (`stage-3-journey-design.md`), Stage 4 (`stage-4-training.md`) and section 3.3, the three-register translation (`section-3-3-three-registers.md`). Section 3.4, the filter test, is a `vios-core` skill because every stage that writes language uses it.

Each stage closes with the manuscript's coherence test and a harvest note in `[client]/archive/`. Stage 4 closes thirty days after opening, with the engagement retrospective.
